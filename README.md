# 校园购数据库设计 V0.2

数据库：PostgreSQL。学校范围：永久只支持明德中英文学校，不建设多学校租户隔离。

## 交付说明
本仓库用于保存校园购数据库设计文件。V0.2 当前为设计草案，尚未执行数据库迁移或部署；正式 SQL 必须先与完整 V0.1 schema 和存量数据核对，并在测试库验证。

## 已确认规则
- 商品支持商家自定义规格/SKU、独立库存流水；不限库存需平台授权。
- 商品售罄自动显示售罄；订单按提交时价格快照执行。
- 多店铺订单按店铺计算运费；支持分批发货。
- 允许按商品/数量/金额部分退款；退款冻结商家待结算资金。
- 校园钱包用于应用内支付；充值和提现为例外路径。
- 财务采用双重记账；不允许直接修改钱包余额；大额调整双人审核。
- 管理员按岗位分权；最高创始人授权需要强身份验证和审计。
- 通知、消息、隐私、文件授权、数据导出和注销均需留痕。
- 平台费率、租金、商家额度和优惠政策版本化，订单保留历史快照。

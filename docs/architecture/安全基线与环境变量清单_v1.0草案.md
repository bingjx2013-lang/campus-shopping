# 校园购安全基线与环境变量清单 v1.0（草案）

## 1. 安全基线
- 密码使用成熟密码哈希算法（Argon2id 或经审查的 bcrypt 参数）；禁止明文、可逆加密或自制算法存储密码。
- 登录、验证码、密码重置和敏感操作实施速率限制、异常检测及防暴力破解。
- 新设备登录要求额外验证；验证码有效期按已确认规则为 2 分钟，且一次性使用、限制尝试次数。
- Cookie 会话启用 Secure、HttpOnly、适当的 SameSite；变更密码、退出全部设备和高风险事件支持撤销会话。
- 实施 CSRF、XSS、SQL 注入、SSRF、开放重定向和越权访问防护。
- 管理后台启用 MFA；财务与高风险操作二次确认和双人审批。
- 密钥只存放在部署平台 Secret/环境变量中；禁止提交真实密钥、访问令牌、数据库密码或生产数据。
- 日志不得记录密码、验证码、完整支付凭据、访问令牌或不必要的个人敏感信息。
- 对数据库执行最小权限；应用运行账号不得拥有 schema owner/superuser 权限。
- 配置备份、恢复演练、告警、依赖漏洞扫描和安全事件响应流程。

## 3. 环境隔离
- local、test、staging、production 使用不同数据库、存储桶、密钥和第三方凭据。
- .env 文件必须加入 Git 忽略规则；仅提交不含秘密的 .env.example。
- 生产密钥使用密码管理/平台 Secret 管理，定期轮换并记录负责人。
- 不得在聊天中粘贴真实密钥、验证码、数据库连接串或访问令牌。

## 4. 上线前安全验收
- 身份认证、会话固定、会话撤销、CSRF、CORS、MFA 和新设备验证测试。
- 买家/商家/后台跨角色、跨用户、跨店铺越权测试。
- 下单幂等、库存并发、支付回调重放、退款重复提交和结算重复执行测试。
- 文件上传类型伪造、超大文件、恶意内容和私有文件越权下载测试。
- 依赖漏洞扫描、秘密扫描、日志脱敏和备份恢复演练。
- 未完成高风险测试不得接入真实资金或开放公众注册。

## 5. 未决事项
- 登录方式、短信/邮件供应商、支付渠道、对象存储供应商尚未最终确认。
- 校园钱包是否只允许校内资金流转及充值/提现规则，需以产品规则和合规审查为准。
- 本文是安全设计清单，不代表这些控制已经实现或通过测试。

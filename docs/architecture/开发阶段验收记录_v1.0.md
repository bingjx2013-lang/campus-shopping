# 应用骨架阶段验收记录 v1.0

## 已提交
- Next.js App Router、React、TypeScript 项目基础配置。
- 面向手机的首页预览。
- GET /api/health 健康检查接口。
- GET /api/v1/products 商品列表接口骨架，支持 page/pageSize 参数校验。
- 商品列表类型定义与统一 API 错误响应辅助函数。
- 环境变量示例和 Git 忽略规则。

## 当前行为与限制
- 商品接口暂时返回空列表；没有连接数据库，不会伪造商品、价格或库存。
- 健康检查只表示 Next.js 进程可响应，不表示数据库、支付或其他依赖已就绪。
- 尚无注册、登录、会话、角色授权、商品管理、库存预占、订单、校园钱包或支付功能。
- 尚未安装依赖、生成 lockfile、运行 lint/build 或端到端测试；GitHub 文件存在不等于构建通过。

## 下一阶段验收门槛
1. 在受控构建环境安装依赖并提交 lockfile，锁定依赖版本。
2. 通过 lint、TypeScript 检查和 production build。
3. 认证接入前确认账号标识、学生/监护人关系、商家员工和后台角色模型。
4. 在隔离测试数据库验证 RLS、越权访问、并发库存和财务账务规则。
5. 通过安全验收前不开放公众注册或真实交易。

## 阻止生产上线的风险
1. SQL 仅为草案，未在 PostgreSQL 执行。
2. journal entry 借贷平衡需跨行延迟约束触发器；现有 CHECK 不足以保证。
3. 当前没有库存预占状态机，不能据此宣称不会超卖。
4. 退款冻结分配、商家欠款和结算暂停缺少完整明细表。
5. outbox 尚未建立，不能保证事务后消息可靠投递。
6. 认证结构不是完整认证实现，仍需限流、密码哈希参数、MFA/找回和设备策略。
7. 未与现有应用代码、生产数据和 API 核对。

## 禁止
- 不要在生产数据库执行 draft SQL。
- 不要将未经测试的迁移合并到生产分支。
- 不要直接修改钱包余额、已完成分录或历史订单快照。
- 不要将私有对象存储桶设为公开。

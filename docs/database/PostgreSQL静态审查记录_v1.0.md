## 结构与业务风险（尚未实现）
- 库存预占表本身不会防止超卖；应用事务必须锁定 SKU 行并原子校验可售库存。
- Outbox 表本身不会投递消息；仍需可靠租约、重试、消费幂等和死信处理。
- 钱包与复式账本需要受控过账函数及数据库权限隔离，不能由普通应用路径任意改余额或历史分录。
- 退款冻结、欠款、结算冻结、提现状态需要事务服务和状态机约束。
- 登录验证码 2 分钟有效期、尝试次数、发送频率、设备验证与会话轮换必须由认证服务落实，不能只依赖表结构。
